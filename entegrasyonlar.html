Teknik Protokol ve Webhook Dokumantasyonu

JSON Webhook Veri Akisi

VerimliAI entegrasyon katmani, olay tabanli (event-driven) mimariyle calisir. Instagram DM'de bir mesaj alindiginda, ManyChat bu olayi bir JSON payload olarak Make.com webhook'una iletir. Make.com, gelen JSON'u parse eder, OpenAI API'ye gonderir, donen yaniti tekrar JSON formatinda paketler ve Shopier ya da WhatsApp API'ye yonlendirir. Tum bu zincir, milisaniyeler icinde tamamlanir.

WhatsApp Cloud API Protokolu (Meta)

WhatsApp Business API, Meta'nin Cloud API'si uzerinden erisilir. Webhook yapilandirmasi su asamalardan olusur: (1) Meta Developer Console'da uygulama olusturma ve WhatsApp product'inin eklenmesi, (2) Webhook callback URL'sinin tanimlanmasi (messages, message_template_status_update olaylari), (3) verify_token ile URL dogrulamasi, (4) Kalici erisim tokeni (Permanent Access Token) olusturma. Tum mesajlasma, 24 saatlik musteri hizmeti penceresi (Customer Service Window) icinde ucretsizdir. Bu pencere disindaki mesajlar, onayli mesaj sablonlari (Message Templates) uzerinden gonderilir.

Instagram Graph API Protokolu (Meta)

Instagram Mesajlasma API'si, Instagram Professional (Business/Creator) hesaplari icin kullanilabilir. API uzerinden su islemler yapilabilir: mesajlari okuma (GET /conversations), mesaj gonderme (POST /messages), medya gonderme (POST /messages + attachment), Icebreaker sorulari yonetme, El sikisma protokolu (Handover Protocol) ile insan operatore devretme. Rate limiting: Sayfa basina saniyede 25 API cagrisi. Webhook olaylari: messages, messaging_postbacks, message_reactions.

Make.com Otomasyon Senaryosu Mimarisi

Tipik bir VerimliAI otomasyon zinciri Make.com uzerinde su modullerden olusur: (1) Webhook Trigger — Instagram/DM'den gelen mesaji yakalar, (2) OpenAI Module — GPT-4o'ya mesaji gonderir, intent analizi ve yanit uretir, (3) Router — intent'e gore akisi dallandirir (stok sorgulama → Shopier API, kargo sorgulama → Kargo API, iade talebi → Operator bildirimi), (4) HTTP Module — ilgili API'ye istek atar, (5) Google Sheets Module — tum etkilesimi loglar. Bu zincir, sifir kod yazilarak, surukle-birak mantigiyla dakikalar icinde kurulabilir. Her modulun hata yakalama (error handling) ve yeniden deneme (retry) konfigurasyonu aktiftir.
