API Dokumantasyonu

VerimliAI API'leri ile kendi sistemlerinizi entegre edin. REST API, Webhook ve SDK dokumantasyonu.

Baslarken

VerimliAI API, RESTful mimariyle calisir. Tum istekler JSON formatinda yapilir ve yanitlar JSON olarak dondurulur. API anahtarinizi almak icin hesap olusturmaniz gerekmektedir.

Kimlik Dogrulama

Tum API istekleri Authorization: Bearer YOUR_API_KEY header'i ile yetkilendirilir.

# API Anahtari ile istek ornegi curl -X GET "https://api.verimliai.com/v1/agent/status" \ -H "Authorization: Bearer vlm_sk_xxxxxxxxxxxx" \ -H "Content-Type: application/json"

API Endpointleri

GET /v1/agent/status

AI asistanin anlik durumunu, aktif kanallari ve son 24 saatlik metrikleri dondurur.

// JavaScript Fetch Ornegi const response = await fetch('https://api.verimliai.com/v1/agent/status', { headers: { 'Authorization': 'Bearer vlm_sk_xxxx' } }); const data = await response.json(); // { status: "active", channels: ["instagram","whatsapp"], messages_24h: 247 }

POST /v1/messages/send

Belirtilen kanaldan musteriye AI tarafindan olusturulmus veya manuel mesaj gonderir.

# Python Istek Ornegi import requests response = requests.post( "https://api.verimliai.com/v1/messages/send", headers={"Authorization": "Bearer vlm_sk_xxxx"}, json={ "channel": "instagram", "customer_id": "cust_123", "message": "Siparisiniz kargoya verildi!" } )

POST /v1/webhooks/register

Webhook kaydi olusturur. Belirli olaylar gerceklestiginde (yeni mesaj, satis tamamlandi) sizin sunucunuza HTTP POST istegi gonderilir.
