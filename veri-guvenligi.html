Veri Guvenligi Garantisi

Musterilerinizin verileri bizim icin kutsaldir. VerimliAI olarak en ust duzey veri guvenligi standartlarini uyguluyoruz.

🔒
Sifreli Veri Aktarimi
Tum veri iletimi SSL/TLS sifreleme ile gerceklesir. Musteri bilgileri hicbir zaman acik metin olarak saklanmaz veya iletilmez.
🚫
API Verileri Egitimde Kullanilmaz
Kullandigimiz OpenAI API, musteri verilerinizi AI modellerini egitmek icin kullanmaz. Bu, OpenAI'nin resmi API veri kullanim politikasi geregidir. Verileriniz sadece sizin hesabiniza ozeldir.
📋
KVKK Tam Uyumlu
6698 sayili KVKK kapsaminda veri sorumlusu sifatiyla tum yukumluluklerimizi yerine getiriyoruz. Detayli KVKK Aydinlatma Metnimize sitemizden ulasabilirsiniz.
📁
Veri Sahipligi Sizde
Sisteme yuklediginiz tum veriler (urun katalogu, fiyat listesi, SSS) size aittir. Sozlesme sonlandiginda verileriniz 30 gun icinde tum sistemlerimizden silinir.
🏛️
Avrupa Sunuculari
Verileriniz Avrupa Birligi sinirlari icindeki sunucularda saklanir. GDPR ve KVKK uyumlulugu en ust seviyede saglanir. Veriler yurt disina aktarilmaz.
🛡️
Yetkisiz Erisim Engeli
Sistemlerimize erisim iki faktorlu kimlik dogrulama (2FA) ile korunur. Sadece yetkilendirilmis personel, sadece gorevi icin gerekli verilere erisebilir. Tum erisimler loglanir.

OpenAI API Veri Kullanim Politikasi

OpenAI'nin resmi API politikasi geregi, API uzerinden gonderilen veriler OpenAI tarafindan AI modellerini egitmek icin kullanilmaz. Bu, ChatGPT'nin ucretsiz surumunden farkli olarak, API kullanicilarina sunulan bir guvencedir. Sizin isletmenizin musteri diyaloglari, siparis bilgileri ve diger tum verileri sadece sizin hesabiniza ozel olarak islenir ve ucuncu taraflarla paylasilmaz.
